# Use # to build title.
	 # Title1
	 ## Title2
	 ### Title3
	 #### Title4
	 ##### Title5
	 ###### Title6

> # Title1
> ## Title2
> ### Title3
> #### Title4
> ##### Title5 
> ###### Title6
---
# Bold and italics
## Use ** to build bold word (Ctrl + B)
	**Bold word**
>**Bold word**
## Use * to build italics word(Ctrl + I)
	*Italics word*
>*Italics word*
---
# List, quote and Todo
## Use - to build list
	- list1
		- list_1
	- list2
> - list1
> 	- list_1
> - list2

You can also use * or + to build list, and 1. can build list with index.
## Use > to build quote
	>Hi
>Hi

(The line before "Hi" is the quote)
## Use [] to build Checkbox
	- [ ]Say hi
> - [ ] Say hi
